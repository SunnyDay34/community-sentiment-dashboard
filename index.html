THE DASHBOARD FILES ARE OK

This page was opened directly as a file. The dashboard uses React, so it needs to be served by its development server or deployed to Vercel; opening index.html directly cannot start the app.

TO PREVIEW ON YOUR COMPUTER
  1. Install Node.js from nodejs.org.
  2. Open Terminal in the unzipped community-sentiment-dashboard folder.
  3. Run npm install, then npm run dev.
  4. Open the local address shown in Terminal (usually http://localhost:5173).

For a public site, upload this project to GitHub and import it into Vercel. See README.md in the project folder for step-by-step instructions. The project opens with demo data.
